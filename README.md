Recipe Recommender
Recipe Recommender helps users discover recipes using ingredients they already have, making it easier to use leftovers and explore different cuisines. Recipe data comes from TheMealDB and is stored in a local PostgreSQL database.

Features
- Search by ingredients, minimum ingredient matches, and cuisine category.
- View recipe ingredients, measurements, source links, and YouTube videos.
- Click an ingredient to see suggested substitutions.
- Uses cuisine category labels generated by a fine-tuned DistilBERT model.

Technology
The application uses Node.js and Express with an HTML, CSS, and JavaScript frontend. Python scripts handle database population, ingredient and measurement normalization with spaCy, model training with PyTorch and Transformers, and substitution generation through Ollama.

Project structure
- server.js — Express server and commented out Supabase API integration.
- public/ — Frontend page, styles, and background image.
- database/ — Data preparation, database population, cuisine classification, and ingredient substitution scripts.
- langModel/ — DistilBERT training and testing scripts.
- databaseAPI.py — Flask API used for the earlier local backend.
- vercel.json — Vercel deployment configuration.

Running locally
With Node.js installed, install dependencies:
npm install
Start the application:
npm start
In a second terminal:
python .\databaseAPI.py
Open http://localhost:3500. Enter ingredients separated by a comma and space, such as eggs, milk, flour, choose the minimum number of matches, and select a cuisine or Any.
